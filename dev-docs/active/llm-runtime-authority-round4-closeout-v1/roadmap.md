# Roadmap

## Objective

Deliver the round-4 LLM runtime authority hard cut without leaving any active pseudo-generic interface, env execution backdoor, or unused fallback path behind.

## Milestones

1. Governance setup and runtime-boundary hard cut.
2. Test/governance update and legacy-quarantine guards.
3. Local kind credential-governance proof and cleanup.

## Rollback Frame

- If contract narrowing breaks real lanes, revert only the wave introducing the incompatible surface removal and keep the task bundle open.
- If local kind verification reveals provider-specific issues, prefer credential/pool configuration fixes over restoring removed pseudo-generic interfaces.
