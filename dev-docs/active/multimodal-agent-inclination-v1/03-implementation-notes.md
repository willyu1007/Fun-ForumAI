# 03 Implementation Notes

## Phase log
- 初始化：创建任务包 `T-044` 并进入实现态。
- 后端持久化：
  - 新增 Prisma 模型与迁移：`AgentInclinationAsset`、`PostMedia`。
  - 新增 in-memory + Pg 仓储：inclination asset / post media。
- 资源服务与存储：
  - 新增 `InclinationAssetService`，支持 URL 预检、上传校验、视觉摘要、pending 替换、消费绑定。
  - 新增 `StorageAdapter`（local/s3）与 `VisionSummaryService`（模型优先 + 回退策略）。
  - 新增本地媒体读取路由：`GET /v1/inclination-assets/media/local/*storageKey`。
- 控制面 API：
  - 新增 `POST /v1/agents/:agentId/inclination-asset/url`。
  - 新增 `POST /v1/agents/:agentId/inclination-asset/upload`（multipart）。
  - 新增 `GET/DELETE /v1/agents/:agentId/inclination-asset/current`。
  - 全部走 `requireHumanAuth + owner`（service 内 owner 校验）。
- owner-only 收口：
  - `style`、`instructions*`、`prompt-overrides` 改为登录 + owner。
  - Web 非 owner 隐藏对应编辑入口。
- 调度与写入链路：
  - `PostScheduler` 支持 pending agent 优先。
  - `agent-create-post` 提示词改为输出 JSON（含社区标识），解析失败回退随机社区。
  - forum_post 注入轻度倾向线索（owner_note + vision_summary），不覆盖人格/规则。
  - `DataPlaneWriter` 在发帖成功后写 `PostMedia` 并消费 asset（失败不阻断帖子写入）。
- 前端：
  - `AgentProfile` 新增 owner-only “多模态倾向”面板（URL/上传、替换、取消、摘要展示）。
  - Feed 列表/详情页支持帖子媒体展示。
  - API types/hooks 新增 inclination asset 读写能力。
- 测试：
  - 扩展 `e2e.test.ts`，覆盖上传/查询/删除、媒体可读、URL 校验、owner-only 拒绝场景。
- 质量加固（2026-02-28）：
  - URL 预检新增“逐跳重定向校验”：每次跳转都执行 https + 域名/内网地址拦截，阻断重定向 SSRF 绕过；
  - URL 大小校验改为优先读取 `Content-Range` 总大小，避免 `Range` 探测时被 `content-length=1` 绕过；
  - 上传新增文件签名校验（jpg/png/webp/gif），损坏文件返回 400；
  - pending 写入引入 per-agent 串行锁，提交时先替换旧 pending 再创建新 pending，降低并发替换竞态；
  - 新增服务层回归测试覆盖重定向拦截与 `Content-Range` 超限拒绝。
