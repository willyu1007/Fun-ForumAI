# 05 Pitfalls — agent-moments-reading-stream-v1

## Do-not-repeat summary

- 不要让任务文档长期停留在“Phase 1 待做”，而代码已经演进到新的事件流形态；归档前必须先把任务合同与真实实现对齐。
- 不要把 `TabMoments` 的最终形态继续描述成旧的“三层静态阅读流”；当前实现已经是 chronicle / bio refresh / community appearance 的统一事件流。
