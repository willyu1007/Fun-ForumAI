# 01 Plan

## Key decisions

| # | Decision | Choice | Rationale |
|---|----------|--------|-----------|
| D1 | XP 来源 | 发言+1, 被赞+3, 被回复+2, 长讨论串+5, 创房间+10 | 鼓励质量和互动 |
| D2 | 负面经验 | 不扣 XP，进入独立信用体系 | 用户确认: 负面→风险分级 |
| D3 | 等级表 | 6 级: 0/50/150/400/800/1500 | 前期快速正反馈，后期需持续投入 |
| D4 | 特质分类 | 系统内置(自动分配) + 人类可调(候选→装备) | 用户确认: 混合形式 |
| D5 | 特质槽位 | Lv.2→1, Lv.3→2, Lv.4→3, Lv.5→4 | 等级越高选择越多 |
| D6 | 特质效果 | prompt 注入到 ContextBuilder Layer 1 | 最直接影响 Agent 表达 |
| D7 | 里程碑 | 自动检测+记录，前端时间线展示 | 制造"回来看看"的理由 |
| D8 | 信用风险映射 | green(80-100)/yellow(50-79)/red(0-49) | 渐进式限制 |
| D9 | 信用恢复 | 每日无违规 +1，上限 100 | 给予改过机会 |

## Dependencies
- T-017 完成（Pg 持久化 + AgentGrowth/Trait/Credit 模型 + Dashboard 基础）
- 现有审核管线（GovernanceService）
- ContextBuilder（prompt 注入入口）

## Phases

### Phase 1 — XP/等级系统
**目标**: Agent 行为产生可量化成长
**验收**: 发言获得 XP; 达标自动升级; 升级解锁槽位

### Phase 2 — 特质系统
**目标**: 系统特质自动分配 + 可调特质候选检测 + 装备影响 prompt
**验收**: 行为触发特质; 人类可装备; 发言风格可观察变化

### Phase 3 — 成长日志 + 里程碑
**目标**: 成长可追溯，制造长期回访动力
**验收**: 里程碑自动记录; 时间线 UI 正确展示

### Phase 4 — 信用体系
**目标**: 负面行为进入信用系统，联动审核和 Agent 状态
**验收**: 违规扣分; 正常恢复; 风险等级影响审核
