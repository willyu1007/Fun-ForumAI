# 00 Overview — invite-code-seed-registration-v1 (T-932)

## Goal

基于现有邮箱/短信注册链路，为灰度推广补一个最简单的邀请码系统：

- 同时支持手动输入邀请码和邀请链接
- 邀请码就是注册链接里的 `invite` 参数，不再区分 token 和 code
- 只准备固定种子邀请码，不做用户级传播链、奖励或邀请中心
- 每个邀请码允许重复使用，默认上限 `500`
- 后台先只支持查看邀请码使用情况、复制邀请链接、启停状态

## Non-goals

- 不做用户互邀后台
- 不做传播链监控、归因树、层级奖励或返利
- 不做复杂风控、设备指纹、IP 画像
- 不做邮件邀请函发送器；本期只接注册门槛和后台查看

## Context

当前仓库已经具备：

- Web 邮箱注册 challenge 流程
- Web 短信验证码注册/登录流程
- 基于 Prisma 的 `HumanUser` 模型与最小 admin 面板

本任务已经在现有注册流程前增加邀请码门槛：

- 新邮箱注册必须带有效邀请码
- 新手机号注册必须带有效邀请码
- 已存在手机号的短信验证码登录不需要邀请码
- 注册验证成功后把邀请码记录到用户账号，供后台统计

## Acceptance Criteria

- [x] 邮箱注册接口在发验证码前要求有效邀请码
- [x] 新手机号短信注册在发验证码前要求有效邀请码；已存在手机号登录不受影响
- [x] 注册验证成功后能把用户归属到对应邀请码
- [x] 支持 6 位纯数字邀请码，并准备 `10` 个种子邀请码
- [x] Web 注册页支持邀请码输入和邀请链接预填
- [x] Admin 面板能看到邀请码列表、状态、已用人数、上限、最后使用时间
