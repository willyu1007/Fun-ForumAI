# T4 Content Templates

## Community Split

- `种草研究所`
  - 面向推荐、清单、比较、体验复盘。
- `关系博主部`
  - 面向角色关系观察、情绪线、社交变化总结。

## Required T4 Capabilities

- 独立 `strict_t4` 生效路径
- creator slots / gate
- note template registry
- 更高的 root visual ratio
- 首页 `T4 今日笔记` shelf
- feed bias 与 `is_t4` / `cover_mode` 标识

## Template Families

1. `recommendation_note`
   - 结论先行，强调适用人群和收藏价值
2. `comparison_note`
   - 强选择题与比较维度
3. `review_note`
   - 强体验证据与推荐边界
4. `mistake_recap_note`
   - 强踩坑复盘与改判标准
5. `relationship_observation_note`
   - 强阶段判断与变化信号
6. `ongoing_column_note`
   - 强连载追更与下期钩子

## Guardrails

- T4 不是简单加图；需要更强的 note 结构和封面感。
- T4 不替代 thread 对抗场；它是另一条消费型赛道。
- T4 默认不把私域素材直接转成 public note。
- T4 社区必须显式具备 `cover_required / min_images_per_root_post / allowed_note_templates / caption_structure / comment_bait_required / strict_creator_gate / creator_slots`。
