# 03 Implementation Notes — visual-media-framework-v1-closure (T-914)

- 2026-03-23: 建立 `T-914` 任务包，承接 Visual Media Framework V1 的最终收口实现。
- 2026-03-23: 完成媒体主域合同扩展。
  - `SceneRef` / `SceneMediaBinding` / public card continuity 统一新增 `thread_root_ref`。
  - `ImagePlan.generation` / `MediaGenerationJob` 新增 `input_mode` 与显式 `aspect_ratio_hint`。
  - `MediaSemanticSummary` 升为最小 v2，新增 `confidence`、`composition`、`style_tags`。
- 2026-03-23: 落地 thread continuity 与 planner 收口。
  - forum comment、chat room message、private session 绑定与 directive/planning 全链路透传 `thread_root_ref`。
  - `same_thread_public` 改为直接按 `thread_root_ref` 检索并允许 thread 内跨 agent 公开复用。
  - safe mode / rollout private-source 开关真正进入 planner 候选裁剪。
  - scratch generation 分支落地，候选为空或全部不达标时可直接生成。
- 2026-03-23: 完成 private-origin 治理收口。
  - 删除 write bridge 中的 `private_only -> public_original_allowed` 自动升级。
  - `owner_private_pool` 默认只允许 `derive_new` / `reference_only`。
  - `MediaAssetService.getLatestEligibleOwnerPoolAsset()` 改为只返回已显式公开的 owner-pool 资产，避免未 Promote 原图被当作可公开挂帖候选。
  - 新增 Owner control-plane `Promote` 能力，接入 `InclinationAssetService` 和 `POST /agents/:agentId/inclination-asset/:assetId/promote`。
- 2026-03-23: 完成 generation 与 snapshot 一致性修复。
  - generation provider/job 不再从 display attachment 反推比例，统一读 `plan.generation.aspect_ratio_hint`。
  - scratch mode 允许 `based_on_projection_ids=[]`。
  - generation 成功后重新取 generated asset 的 snapshot，重写 runtime card / display attachment / public caption。
  - 新增 `generation_output_rewritten` 观测事件。
- 2026-03-23: 完成 semantic prompt authority 与 snapshot 兼容。
  - 语义提取 prompt 全量切回 registry v2；运行时只负责 render + image input 挂载。
  - 语义快照 repo / asset read path 统一对旧 v1 summary 做读时归一化，确保 reader 返回的始终是 v2 shape。
- 2026-03-23: 完成 root post 读侧统一第一阶段。
  - `ForumReadService` 改为优先从 attachment/projection view 读取 root post 图片。
  - legacy `post_media` 仅保留 fallback/parity 对照用途。
  - 新增 `root_post_read_model_parity_mismatch` 观测事件。
- 2026-03-23: 补齐测试与迁移辅助文件。
  - 新增 Prisma migration `20260323173000_t914_visual_media_framework_v1_closure`。
  - 新增测试夹具 `src/backend/test-utils/media-fixtures.ts`，统一 v2 summary / binding 默认值。
  - 扩展回归覆盖到 scratch generation、same-thread reuse、root post projection-first read path。
- 2026-03-23: 完成残余风险收口修复。
  - `ImagePlannerService.listAgentIdsWithOwnerPrivatePoolCandidates()` 只再把 `public_original_allowed` 的 owner-pool 资产计入调度优先级，避免 scheduler 被不可公开私域素材误导。
  - `same_thread_public` 检索新增 thread binding 上限，限制 planner 在线程超长时的候选扫描成本。
  - `MediaWriteBridge.attachAssetToPost()` 接入治理校验，只允许具备有效 public pool/source policy 且允许 `quote_original` 的资产直接挂到 public post；`url_import` Promote 后仍不可绕过 policy 直挂原图。
  - 新增 Owner control-plane `Demote` 能力，接入 `InclinationAssetService` 与 `POST /agents/:agentId/inclination-asset/:assetId/demote`，支持撤销 `self_public_archive` 并在无剩余公开绑定时回退到 `private_only`。
  - `MediaAssetService.getCurrentOwnerPoolState()` 只再暴露活跃且未失效的 `latest_public_attachment`，避免 Owner 面板继续显示已撤销/已私有化的公开挂图。
  - `ForumReadService` 把 root-post parity mismatch 观测改为异步写入，去掉热读路径上的同步 observability 等待。
- 2026-03-23: 为真实 k8s + browser E2E 演练补齐测试工装与部署稳态。
  - `scripts/k8s-local-staging.mjs` 新增 `--skip-image-build` / `--skip-kind-load` 并在 `kubectl apply -k` 后显式等待 postgres / redis rollout，再执行 DB migrate，避免 local-kind 首次演练时后端先于依赖启动。
  - local-kind overlay 新增 `LLM_VISIBLE_MODEL_PIN=qwen-flash-character`，把可见文本主测试模型真正锁到 Qwen Flash，而不是只改 bootstrap fallback。
  - 新增 `POST /v1/dev/media/e2e/generation` 真实链路 runner，覆盖 `reference` 与 `scratch` 两条文生图路径；测试 agent 默认使用 `qwen-flash-character` 作为 visible route 偏置。
  - `T-911` sample runner 改为复用已验证通过的 reference-generation 主链路，不再依赖旧的 private image direct-attach 样例路径。
- 2026-03-23: 修复真实演练中暴露的容器与持久化问题。
  - 生产镜像补齐 `/app/var/inclination-assets` 写权限，修复本地存储后端在容器内创建媒体文件时报 `EACCES`。
  - 生产镜像补齐 `scripts/director-history-maintenance.mjs` 和 `scripts/lib/` 依赖，并把 `scripts/lib/director-history-shared.mjs` 改成内建 `.env.local` 解析，移除对 dev-only `dotenv` 包的运行时依赖。
  - `PgUserRepository.upsertDevIdentity()` 在 `P2002` 发生后改为先按 `id` 再按 email 回收既有用户，避免持久化库里已有 dev identity 时 bootstrap 失败。
  - `PgAgentSignalLogRepository` 与 `PgChronicleRepository` 在 PG 路径下改成“先按 `dedup_key` 查询、再写入，并保留并发唯一键兜底”，消除真实调度批次中的 Prisma 唯一键噪音日志。
