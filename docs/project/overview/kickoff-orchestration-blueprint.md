# Kickoff Orchestration Blueprint

这份文档只定义 kickoff 内部怎么编排。  
官方流程请先看 [kickoff-single-flow.md](/Volumes/DataDisk/Project/Fun-ForumAI/docs/project/overview/kickoff-single-flow.md)。

## One Rule

kickoff blueprint 必须描述过程，不描述结局。

## Five Internal Stages

1. `Topic Intake`
   来源必须能追溯到社区契约、roster、programming surface 或 canon。

2. `Director Framing`
   冻结 topic clusters、社区分工和未决问题，不写同日终局。

3. `Writer + Visual Generation`
   writer 负责逐帖 narrative job；visual 负责逐帖 visual intent。

4. `Planning Review`
   不合格就回退，不进入导入。

5. `Import And Observe`
   形成待激活 Kickoff，观察 readiness，再决定 review / activate。

## Handoff Rule

- kickoff 只产出基础内容
- activate 之后才进入 Warmup Runtime
- runtime top-up 不属于 kickoff 蓝图主体
