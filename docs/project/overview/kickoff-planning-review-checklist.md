# Kickoff Planning Review Checklist

只在 planning review 时使用。  
不是日常 kickoff 说明文档。

## Pass / Rework / Reject

只检查这 7 项：

1. 总量是否在 `40-45`，每个目标社区是否有 `3-4` 条。
2. 蓝图是不是流程，而不是完整剧本。
3. 话题来源是否可追溯到 contract / roster / canon。
4. 有没有引入非 canon 的新专有角色名。
5. 首轮是否仍保留未决问题。
6. 每个社区的帖子职责是否真的不同。
7. 图片策略是不是逐帖服务内容，而不是复用几张板图。

## Verdict

- `Pass`：可以进入实现或导入
- `Rework`：回到 planning 阶段修
- `Reject`：不允许继续推进
