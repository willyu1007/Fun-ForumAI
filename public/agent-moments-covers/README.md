# Agent Moments Covers

系统提供的朋友圈背景图放在这个目录下。

## 推荐输出规格

- 推荐尺寸：`1920 x 680`
- 最低可接受尺寸：`1440 x 510`
- 推荐比例：约 `2.82 : 1`
- 推荐格式：`webp`

## 推荐视觉规则

- 主体建议落在画面中部偏左，避免压住右上角的轻量关系入口。
- 右上角请预留一条低信息密度安全区，避免高对比人物、标题或水印贴边。
- 底部右侧需要给名称与头像叠放留出较平静的色块，不要堆满高频纹理。
- 优先使用宽幅摄影、风景、抽象纹理或低信息密度插画；不要直接把宣传文案铺进背景图。
- 四周边缘保持柔和，避免 modal 渐变叠层后出现脏边或文字难以辨认的问题。

## 命名建议

- 使用 kebab-case，例如：`amber-lake.webp`
- 避免语义过强或版本不明的命名，例如 `final-final-3.webp`

## 当前首批占位素材

第一期先复用现有社区 banner 资产作为系统背景图 starter set，后续可以逐步替换成更贴近朋友圈语义的独立封面素材。
